# House Price Prediction Using Ensemble Learning

## Project Overview
This project predicts house prices using machine learning and ensemble learning techniques.

## Dataset
California Housing Dataset.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Random Forest Regressor

## Methodology
1. Data Loading
2. Data Cleaning
3. Missing Value Handling
4. One-Hot Encoding
5. Train-Test Split
6. Random Forest Regression
7. Model Evaluation

## Model Performance

- MAE: 31639.37
- RMSE: 49038.21
- R² Score: 0.8165

## Result
The Random Forest model achieved an R² score of approximately 81.65% on the test dataset.

The model can be deployed as a web application using Streamlit or Flask.
